# Soul Beer — сайт бара

Стек: Next.js (App Router), TypeScript, Tailwind, PostgreSQL, Prisma, Zod.

## Быстрый запуск на Windows

Двойной клик по `start.cmd`. Он запустит Docker Desktop, базу, применит миграции, откроет браузер и запустит сервер. Коды из SMS в режиме заглушки печатаются в окне `start.cmd`.

- Сайт: http://localhost:3000, админка: http://localhost:3000/admin/login.
- `studio.cmd` открывает Prisma Studio на http://localhost:5555.
- Dev-сервер пишет в `.next-dev`, сборка (`npm.cmd run build`) в `.next` (см. `next.config.mjs`), поэтому их можно запускать независимо. Одновременно на порту 3000 может работать только один сервер.
- Команды в PowerShell вызывайте через `npm.cmd`: политика выполнения блокирует `npm.ps1`. Не используйте `npx prisma ...` вне папки проекта: npx скачает чужую версию Prisma.

Полезные команды (из папки `soul-beer`):

| Команда | Что делает |
|---|---|
| `npm.cmd run db:up` | Запустить базу и дождаться готовности |
| `npm.cmd run db:studio` | Prisma Studio |
| `npm.cmd run seed:menu` | Заглушки меню |
| `npm.cmd run owner -- 79001234567 "пароль" "Имя"` | Создать владельца |
| `npm.cmd run verify-phone -- 79001234567` | Только локально: отметить телефон подтверждённым, чтобы проверить бронь и заказ без SMS |

## Запуск вручную

1. `docker compose up -d` — локальная база.
2. `cp .env.example .env` и заполнить `CODE_SECRET` и `SESSION_SECRET`.
3. `npm install` (сгенерирует Prisma Client).
4. `npx prisma migrate dev --name init`.
5. Создать владельца: `node --env-file=.env scripts/create-owner.mjs 79001234567 "пароль от 8 символов" "Имя"`.
6. Добавить столы: `npx prisma studio`, таблица `Table`, поля name, zone, capacity, active = true.
7. `npm run dev`, затем вход на `/admin/login`.

## Что уже есть

- Схема базы (`prisma/schema.prisma`): брони, заказы, меню, афиша, журнал уведомлений.
- Подтверждение телефона по SMS: `POST /api/phone` с `action: "request"` или `"confirm"`. Лимиты: 3 кода в час, 5 попыток на код, срок кода 5 минут.
- Заявка на бронь: `POST /api/bookings`. Принимается только с подтверждённым телефоном.
- Страница брони `/booking`: сначала отправляется заявка, код из SMS запрашивается, только если телефон ещё не подтверждён.
- Отмена брони по ссылке из SMS: страница `/cancel/[token]` и `POST /api/bookings/cancel`.
- Меню `/menu` и заказ `/order`: самовывоз с датой и временем, предзаказ к столу по номеру брони или доставка. Доставка включается флажком в `/admin/settings`, там же часы работы. Бронь и заказы принимаются только в часы работы. Цены берутся из базы, а не от клиента. Заказ требует подтверждённого телефона.
- Админка заказов `/admin/orders`: подтвердить или отклонить, отметить готовность и выдачу. Гость получает SMS на каждый переход.
- Заглушки меню: `node --env-file=.env scripts/seed-menu.mjs`.
- Админка каталога (владелец и администратор): `/admin/menu` с ценами и стоп-листом, `/admin/tables` со столами и вместимостью, `/admin/events` с афишей и публикацией. Сотрудник зала эти разделы не видит.
- Сервис подтверждения брони `confirmBooking` с проверкой пересечения на столе и вместимости, отмена по токену `cancelByToken` (`src/lib/bookings.ts`).
- Админка `/admin`: вход сотрудников по телефону и паролю (scrypt, подписанная cookie на 12 часов), список новых заявок с подтверждением (выбор стола) и отклонением, ближайшие брони. Отклонение отправляет гостю SMS.

## Заглушки уведомлений

Пока `MAX_ENABLED` и `SMS_ENABLED` не равны `true`, сообщения не отправляются. В консоли в режиме разработки видно текст, а в таблице `notifications` сохраняется статус `stub`. Текст сообщений в журнал не пишется, потому что в SMS бывают коды.

Чтобы подключить:
1. **MAX.** Создать бота через @MasterBot и пройти модерацию. Заполнить `src/lib/notify/providers/max.ts`, указать `MAX_BOT_TOKEN` и `MAX_ENABLED=true`. Сотруднику, который будет получать уведомления, записать `maxUserId` в таблицу `staff` после того, как он запустит бота.
2. **SMS.** Зарегистрировать буквенное имя отправителя. Заполнить `src/lib/notify/providers/sms.ts`, указать `SMSC_*` и `SMS_ENABLED=true`.

Без подключённого SMS проверка телефона не работает. Это ожидаемо: код не уходит, поэтому заявки не создаются.
